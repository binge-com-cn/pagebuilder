# XinTheme PageBuilder
WordPress 拖拽式建站插件的开发者文档。


## 字段类型
01. [Alignment] - 对齐方式选择字段
02. [Animation] - 动画输入字段（wowjs）
03. [Background] - 背景字段
04. [Background2] - 带透明度选项的背景字段
05. [Border] - 边框输入字段
06. [BoxShadow] - 盒子阴影输入字段
07. [Switch] - 单开关输入字段
08. [Checkbox] - 多选框输入字段
09. [Color] - 颜色输入字段
10. [Color2] - 颜色与渐变输入字段
11. [Dimension] - 尺寸输入字段
12. [Editor] - WordPress 默认可视化编辑器字段
13. [Typography2]- 字体样式输入字段（简化设置）
14. [Typography] - 字体样式输入字段（完整设置）
15. [Gradient] - 渐变颜色输入字段
16. [Icon] - 图标选择字段（Remix Icon 与 XTPB 字体图标）
17. [IconSocial] - 社交图标字段
18. [Link] - 链接输入字段
19. [Media] - WordPress 媒体管理器字段
20. [Number] - 数字输入字段
21. [RadioImage] - 图片单选字段
22. [Repeatable] - 可重复分组字段
23. [Select] - 下拉选择字段
24. [Separator] - 分隔字段
25. [Slider] - 可拖拽数字输入字段
26. [Text] - 文本输入字段
27. [TextArea] - 多行文本输入字段
28. [Filter] - CSS Filter 输入字段
