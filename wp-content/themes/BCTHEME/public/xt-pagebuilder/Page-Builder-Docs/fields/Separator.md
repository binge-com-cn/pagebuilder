# Separator
设置面板分隔字段。

## 参数
参数 | 类型 | 说明
--- | --- | ---
type | `required` | 固定字符串（textarea）
title | `optional` | 字符串
desc | `optional` | 字符串
tab | `optional` | 字符串（style）
section | `optional` | 字符串

```php
'addon_separator' => array(
    'type' => 'separator',
    'title' => __('分隔符字段','your-textdomain'),
)
```
